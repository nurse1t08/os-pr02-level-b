# Практическая работа № 2 — уровень B

**Тема:** Bash, обработка журналов и системные вызовы.

## Запуск (Ubuntu)

```bash
sudo apt update && sudo apt install -y python3 strace
bash run.sh
```

`run.sh` создаёт 50 файлов журналов, запускает отчёты ERROR/WARN и снимает две трассы системных вызовов. Если `strace` нет, Bash-часть продолжит работать.

Примеры отдельных команд:

```bash
./report.sh data ERROR
./report.sh data WARN --top 3
python3 hello.py data/01.log
strace -f -yy -o trace_python.txt python3 hello.py data/01.log
strace -f -yy -o trace_cat.txt cat data/01.log >/dev/null
python3 analyze_trace.py trace_python.txt data/01.log
python3 analyze_trace.py trace_cat.txt data/01.log
```

Без параметров `report.sh` показывает справку и возвращает `1`; неизвестный каталог — `2`. Работает в Bash 3.2 и выше, без ассоциативных массивов.

## Анализ

Сначала сравнивается **общее число системных вызовов**, затем число `read`/`pread64`, относящихся именно к `01.log` (по подписи FD от `strace -yy`). Числа надо взять из **реальных** файлов `trace_python.txt` и `trace_cat.txt`; они зависят от ОС и версии Python, поэтому заранее не подставляются.

Ожидаемая причина различия: Python перед чтением файла загружает интерпретатор, библиотеки, конфигурацию, импортируемые модули, выполняет поиск путей и выделение памяти. Утилита `cat` устроена проще; сами `read` и `write` тоже являются системными вызовами.

## Вывод

Bash автоматизирует подсчёт сообщений; `strace` позволяет отделить чтение конкретного файла от дополнительных операций запуска программы.
